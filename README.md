# Guías de marca · GEINT y UMBRAL

Skill de Claude Code con las dos alternativas de identidad para una empresa de gestión integral inmobiliaria (arquitectura, corretaje inmobiliario, corretaje de seguros y regularizaciones).

- `skills/brand-guidelines/SKILL.md`: cómo elegir la marca, reglas comunes y checklist de entrega.
- `skills/brand-guidelines/references/<marca>/DESIGN.md`: tokens y guía completa de cada marca, en el formato abierto de DESIGN.md.
- `skills/brand-guidelines/assets/<marca>/`: logotipos SVG y clip animado.

## Instalar

Copia o enlaza `skills/brand-guidelines` en `~/.claude/skills/` (para todos tus proyectos) o en `.claude/skills/` de un proyecto.
